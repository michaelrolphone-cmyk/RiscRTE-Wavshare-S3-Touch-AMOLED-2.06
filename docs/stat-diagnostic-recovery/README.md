# Waveshare 0.1.60 bounded STAT diagnostic successor

This additive recipe preserves the immutable 0.1.59 producer and release. It changes
only the Runtime diagnostic source, shared Home 0.20.2, the cohort identity, and the
version-specific installed-app catalog feed URL. All other application/provider
inputs, boot policy/grants, storage mapping and all 45 SD files remain exact .59 bytes.
Concurrent native application migrations are not inputs to this diagnostic pair.

The Runtime observations distinguish unbound storage from provider-unavailable and
retained outcomes. They do not establish the physical failure cause. Provider ABI,
wire protocol and retained-state safety remain unchanged. Hardware remains untested.

The native target artifact must prove linked internal/external memory, actual serial
and diagnostic sizes, and retained IQ-bank fit. x86 host size deltas are not target
memory evidence. Publication uses exact-source native qualification, same-run bytes,
independent public readback and canonical known-LoRa association. No hardware handoff
is valid before those steps. Preserve flash, reset, reconnect, then files ordering.
